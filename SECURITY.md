# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Use GitHub's private reporting: on
[nci-gis/rust-commander](https://github.com/nci-gis/rust-commander), open the
**Security** tab and choose **Report a vulnerability**. Say what you found, how to
reproduce it, and which version or commit you used.

We aim to reply within a week.

## Supported versions

Only the latest release, and the `dev` branch, receive fixes.

## What rcmd defends against

See [docs/security.md](docs/security.md): untrusted file names, archives and images,
the safe modes, and what is not covered.
