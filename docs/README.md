# xdevcmd documentation

Read in this order; each page stands on its own.

1. [Guide](guide.md): what xdevcmd does, one topic at a time
2. [Keys](keys.md): every key, as shipped (F1 shows yours)
3. [Shell](shell.md): the terminal panel, and staying in the directory you quit in
4. [Config](config.md): settings, themes, bookmarks, your own commands
5. [Security](security.md): what xdevcmd guards against, read-only and restricted modes
6. [Troubleshooting](troubleshooting.md): known problems on each system, and fixes
7. [Compatibility](compatibility.md): what stays the same from 0.4.0, and what is not promised
8. [Development](development.md): build, test, release, contribute
9. [Testing by hand](testing-by-hand.md): check a release on your machine, then a week of
   real use, data first
10. [Benchmarks](benchmark.md): the speed on your own drives, and comparing two versions

These pages on GitHub's `main` describe the newest code, which may be ahead of yours.
**For the version you have installed, use Help → Documentation** in xdevcmd (or F1, type
"doc"): it names the copy in `docs/` beside the program, when you installed from a
release archive, and the link to these pages at your version's tag.
